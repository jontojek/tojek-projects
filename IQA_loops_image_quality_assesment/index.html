exp06 · Autonomous Image Quality Assessment (IQA) Evolution

65-minute unattended loop on RTX 5090. Self-contained package with local WebP media assets.

1 · Overview & How It Works

This experiment runs an unattended evolution loop on your RTX 5090. Here is how it works step-by-step:

  • Initial Seed Prompt Origin: The starting prompt ("A dense, high-complexity graphic-design composition: a Voronoi stained-glass mosaic filling the frame, each cell a saturated jewel-tone facet with thin glowing lead lines...") was written by us at the start of the experiment to test fine geometric detail, color saturation, and lighting complexity.
  • Image Generation Model: ComfyUI (running locally on port :8188) uses the KREA2 turbo checkpoint (krea2_turbo_fp8_scaled.safetensors) combined with Qwen3-VL-4B clip and Qwen image VAE to render high-resolution 1664×928 frames in 8 steps.
  • Pixel Quality Floor (Image Quality Assessment / IQA): Python uses the standard PIL (Pillow) library to calculate objective pixel checks instantly: Sharpness (Laplacian edge variance), Colorfulness (channel distribution), and Brightness (luminance).
  • AI Vision Judging & Prompt Mutation: The rendered image is sent to your local LLM judge hosted in LM Studio on port :1234 (using the 30B Qwen Vision MoE model, with an 8B model as fallback). The judge scores the image out of 100, identifies its weakest criteria, and automatically rewrites the prompt for the next cycle.
