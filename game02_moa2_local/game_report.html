VFX Space Shooter — Build Report

Project: game02_moa2_local  ·  Date: 2026-07-13  ·  Single-file HTML5 Canvas game

Overview

A top-down 2D arcade space shooter built as a single index.html file using HTML5 Canvas and vanilla JavaScript. No external dependencies, no libraries, no assets. Opens directly in Chrome — zero install, zero server required.

Controls

KeyAction
WASD or Arrow KeysMove ship (diagonal movement normalized)

Architecture — 8 Commented Code Blocks

  • Block 1 — Canvas & Context Setup: Main 800×600 canvas + offscreen canvas for chromatic aberration post-processing. CSS handles responsive scaling; internal resolution stays fixed.
  • Block 2 — Game State & Main Loop: Central game state object. requestAnimationFrame loop with delta-time capped at 50ms (prevents physics explosion if tab is backgrounded). All velocities are px/sec × dt — frame-rate independent.
  • Block 3 — Input Manager: Keydown/keyup listeners feeding a state map. WASD + Arrow keys map to same movement. SPACE fires continuously while held. Separate one-shot keydown listener for R-restart to catch quick taps.
  • Block 4 — Entity Classes: ES6 classes for Player, Projectile, Enemy (3 procedural AI patterns), and Particle. Each has update(dt) and draw().
  • Block 5 — VFX Systems: 3-layer parallax starfield, explosion spawner with screen shake trigger.
  • Block 6 — Game Logic (Update): Player update, enemy spawning (rate scales with score), entity updates, circle-based collision detection, shield/score management, VFX decay.
  • Block 7 — Rendering (Draw): Layered compositing — screen shake → motion trail fill → starfield → particles (additive) → projectiles → enemies → player → chromatic aberration → vignette → HUD → game-over overlay.
  • Block 8 — Reset & Init: Full state reset for new rounds, boot sequence.

Enemy AI — 3 Procedural Patterns

  • Hunter (pattern 0): Tracks player position with sine-wave wobble. Adapts to player movement.
  • Diver (pattern 1): Picks a fixed angle toward player at spawn and flies straight. Predictable but fast.
  • Weaver (pattern 2): Horizontal sine-wave sweep with vertical drift, bounces off side walls. Erratic movement.

Enemy speed scales with score (difficulty ramp). Spawn rate increases as score climbs.

Gameplay Mechanics

  • Shield system: 100 HP, 34 damage per hit = 3 hits to die. Shield bar color shifts green → red as it depletes.
  • Invulnerability frames: 1 second after taking a hit. Player ship blinks during invulnerability.
  • Score: +1 per enemy kill. Spawn rate and enemy speed scale with score.
  • Game over: Big dual-color explosion (cyan + white), overlay with final score and restart prompt.

Performance Notes

  • Delta-time movement — identical speed on 60Hz and 240Hz displays.
  • Entity filtering (not array splicing mid-iteration) for cleanup.
  • shadowBlur set strategically — turned off during trail fill and particle pass to avoid redundant GPU work.
  • Additive blending for particles avoids per-particle shadowBlur cost.
  • Tested on RTX 5090 — runs at locked 60FPS with headroom to spare (this is lightweight 2D Canvas).

Bugs Found & Fixed During Build

  • Chromatic aberration background brightening: Original code cleared offscreen with opaque fill then used pure 'lighter' blend, causing the dark background to brighten during the damage flash. Fixed by clearing offscreen transparently, drawing a base copy at full opacity, then overlaying two offset copies at 0.5 alpha with additive blend.
  • Restart key edge case: The held-state check in update() could miss quick R taps between frames. Added a dedicated one-shot keydown listener that calls resetGame() directly when R is pressed during game-over.
