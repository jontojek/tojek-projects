# Prism Valley

Static Babylon.js 9.9.2 scene viewer. All runtime assets are local to this folder.
Click-to-load keeps the initial blog visit light. The initial lighting and camera
come from viewer-settings.json, copied from the local author's latest saved setup.
Visitor edits are temporary; Export look + view downloads JSON to their computer.

Model and art direction: Jon Tojek; generated with Blender Python and OpenAI Codex.
Babylon.js and its loader: Apache-2.0, https://github.com/BabylonJS/Babylon.js
Environment texture: https://assets.babylonjs.com/environments/environmentSpecular.env

To update the look: copy the desired local saved setup to viewer-settings.json,
test locally, commit and push. Keep .blend sources out of this web repository.
